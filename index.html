How Automatic Synchronization Works (Zero-Cost Setup)

When you conduct a tier test on Discord (e.g., using a Bot), you can easily push player tiers directly to this site without paying for database hosting.

Option A: Discord Bot + GitHub API (Recommended & Free) Have your Discord Bot update a simple players.json file in your free GitHub repository via GitHub REST API whenever a player passes a test. When hosted on GitHub Pages or Vercel, your website auto-fetches this file!
Option B: Tester Admin Panel If you don't use a bot, tier testers can open the Player Editor in this admin panel, type the username & assigned tiers, and hit Save. The site updates rankings instantly.
